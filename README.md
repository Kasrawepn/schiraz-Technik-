
# 🛠️ SCHIRAZ KÜCHENTECHNIK — Landing Page & Service Portal

A modern, fast, and fully responsive single-page landing page designed for **SCHIRAZ KÜCHENTECHNIK** (specialized kitchen installation, moving, and furniture assembly services in the Mönchengladbach region, Germany).

---

## 🚀 Key Features

* **🌐 Multilingual System:**
  * Support for 5 languages (German, English, French, Spanish, Italian)
  * Real-time language switching without page reloads
  * Flag icons in the language selection menu
* **📸 Interactive Before/After Slider:**
  * Visual comparison of completed projects with a manual interactive slider
* **📩 Booking Form with File Upload:**
  * Receive project details along with photo and video uploads directly from customers
* **📱 Fully Responsive:**
  * Completely optimized for mobile, tablet, and desktop viewports
* **⚡ High Performance:**
  * Built with Tailwind CSS CDN and FontAwesome for fast loading times and a modern aesthetic

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, JavaScript (ES6+)
* **Styling:** Tailwind CSS, CSS Custom Properties
* **Icons & Assets:** FontAwesome 6, Flag Icons CDN
* **Deployment:** GitHub Pages
